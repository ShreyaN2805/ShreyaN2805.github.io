## Before publishing

Your GitHub, LinkedIn, email, three project links and DSA repository link have already been added. Review them once before publishing. Also verify that each project description and skill accurately reflects your contribution. Remove any tool or skill you have not used.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named exactly `ShreyaN2805.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root (not inside another folder).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the Pages deployment to finish. Your site will be at `https://ShreyaN2805.github.io`.
